# Capture overlay and selection interaction

Label: wayfinder:prototype
Type: prototype
Status: open
Blocked by: 02

## Question

What does snipping *feel* like? Build the roughest overlay that answers it.

The fullscreen dim overlay: one window spanning the virtual screen, crosshair cursor, the drag-to-select gesture per mode (rectangular / free-form / window / full-screen), the live size readout, Escape and right-click to cancel, and the 1–5s delay. Free-form and window mode change the gesture, so prototype enough of each to feel how they differ. Link the prototype as an asset from this ticket.
